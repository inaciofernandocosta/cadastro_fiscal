## Regra de crescimento

Para cada nova tela critica do produto:

1. Criar uma pasta dedicada com o nome da pagina.
2. Adicionar `PRD.md` com contexto funcional e tecnico.
3. Adicionar `RUNBOOK.md` com operacao, monitoramento e incidentes.
4. Adicionar `FLUXO.md` com mapa ponta a ponta e estados de fluxo.
5. Incluir fluxos de erro, seguranca e operacao.
6. Atualizar este indice.
